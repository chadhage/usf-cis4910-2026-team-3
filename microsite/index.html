    Team progress

    Iteration submission guide

    Create one branch and report per iteration, then open a pull request.

    Open repositoryReturn to microsite
    Required workflow

    One branch per iteration

    1. Start from the latest main branch.
    2. Create a branch named iteration/NN, replacing NN with the two-digit iteration number.
    3. Create iterations/NN/README.md from the required template.
    4. Commit and push the branch to GitHub.
    5. Open a pull request into main and request the required review.
    Command-line example
    git switch main
git pull --ff-only
git switch -c iteration/01
git add iterations/01/README.md
git commit -m "Add iteration 01 update"
git push -u origin iteration/01
    Required README.md template

    Use these headings exactly

    Replace each placeholder, use concise bullets, and link to evidence. Write - None. when there are no impediments.

    # Iteration NN Update

**Iteration dates:** YYYY-MM-DD to YYYY-MM-DD

## Completed

- <Completed outcome and supporting evidence>

## Planned for the Coming Iteration

- <Planned outcome>

## Impediments

- <Impediment, impact, owner, and requested help>
    Before opening the pull request

    Submission checklist

    • The branch follows iteration/NN.
    • The report is located at iterations/NN/README.md.
    • All three required sections are present.
    • Completed work points to inspectable evidence.
    • Impediments identify impact, ownership, and any help needed.
    • The pull request targets main.
